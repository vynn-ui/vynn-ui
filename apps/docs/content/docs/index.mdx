vynn-ui is a React component library built on [Base UI](https://base-ui.com) primitives, shipped
in two complete themes — **Classic** and **Neobrutalism** — that share one token system rather
than being palette swaps of each other.

Every component reads its styling through four layers of tokens: primitive values → semantic
aliases → role tokens → the component itself. A component never reaches past its role token, so
retheming never means touching component code.

## What "two themes" actually means

Classic is soft: rounded corners, subtle 1px borders, quiet drop shadows, Inter for body text.
Neobrutalism is hard: square corners, 3–4px solid-ink borders, an offset hard shadow that
flattens on press, Space Grotesk, and uppercase labels. Both read the exact same component API —
switching theme is one `data-theme` attribute on the page root, nothing in your component tree
changes.
