## Resizable

Custom drag-to-resize panel group (no Base UI primitive). Two or more panels separated by a
draggable handle.

## ScrollArea

A styled scroll container — custom scrollbar chrome over native scrolling.

Both of these get the least automated coverage in the library so far; sanity-check them in
Storybook before shipping with either.
